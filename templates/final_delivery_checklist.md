# Final Delivery Checklist

## Deliverables

- [ ] Publication-ready article document
- [ ] Clean publication copy (no review-only keyword highlighting)
- [ ] Marked review copy, if requested
- [ ] Independent image assets
- [ ] Keyword record
- [ ] Visual asset manifest
- [ ] Dated SERP and original-structure evidence
- [ ] Machine-readable release evidence
- [ ] Completed final editorial QA record with truthful reviewer type; real human approval additionally recorded when the task/project requires it
- [ ] Exact release-file manifest

## Regression checks

- [ ] Source asset audit completed
- [ ] 80–90% effective-information retention, or explicit authorization below 80%
- [ ] Tables preserved or replaced with documented equivalent
- [ ] Cases/evidence/procedures preserved or improved
- [ ] Product portfolio and CTAs preserved or improved
- [ ] Original effective visuals retained or documented replacement
- [ ] Material word-count reduction justified

## Final QA

- [ ] Heading and section logic
- [ ] SERP-backed, topic-specific structure; no reference-outline copying
- [ ] Keyword distribution and naturalness
- [ ] Every exception uniquely approved; every highlight is useful editorial copy
- [ ] Product fit, placement, evidence, limitations, CTA
- [ ] Every named core conversion product classified `direct_supported` has a direct-solution heading and article-visible current official feature URL; no Ultra Tips/adjacent/not-supported residue exists in article or release evidence
- [ ] Every named core conversion product with an adjacent authorized route has a dedicated Ultra Tips H2, truthful boundary, 3 best-for scenarios, not-for route, 4–6 workflow steps, safe CTA, mapped product visual, and decision/FAQ-or-Verdict touchpoints
- [ ] Image count, Alt, captions, asset files, insertion points
- [ ] One or two visual uses per named section, with reader scenario, style, rights, and rendered QA
- [ ] Links, sources, comments/tracked changes
- [ ] Single-release directory purity
- [ ] Clean copy has no comments, tracked changes, placeholders, or review-only notes
- [ ] Render/layout review or explicit visual-QA-pending label
